# duane-claude-plugins

Marketplace index for [Claude Code](https://claude.com/claude-code) plugins by
Duane Nielsen. This repo contains only the marketplace manifest — each plugin
lives in its own repo.

## Install

```
/plugin marketplace add DuaneNielsen/duane-claude-plugins
/plugin install <plugin-name>
```

## Plugins

| Plugin                                                                                | Description |
|---------------------------------------------------------------------------------------|-------------|
| [claude-memory](https://github.com/DuaneNielsen/claude-memory)                        | Conversation memory — extracts atomic facts from past sessions and exposes semantic search via MCP |
| [claude-waybar-status](https://github.com/DuaneNielsen/claude-waybar-status)          | Reports session state to a local waybar-topics server so the workspace's waybar button changes color |
